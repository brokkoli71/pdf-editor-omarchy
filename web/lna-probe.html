Can this page reach your desktop?

Open this from the hosted copy (brokkoli71.github.io) on your phone, with Sidemark sharing on your computer. It answers one question: whether a public-origin page is allowed to talk to your machine, and whether the browser offers to ask you.

What the answers mean. Each test fetches state under the address in no-cors mode, so a refusal is the network refusing, not CORS.

  • Reached it — the request went through. If that happens for the https:// tailnet address, Local Network Access is no longer an absolute block, and the hosted app could speak to the desktop directly.
  • Blocked — the request never left. Expected today for both, and expected for ever for a plain http:// address, which fails mixed content before anything else is consulted.
  • A permission prompt appeared — say so. That is the whole reason this page exists: a prompt that can be granted is a different finding from a silent refusal.
